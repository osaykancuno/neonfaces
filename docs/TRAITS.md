# Traits & exact rarities

Counts are fixed (exact decks), generated by `art/generate.py`, and published before mint. They are exact over the 5555 artworks; which of them are minted depends on the sale.

The 5555 artworks are **3335 single close-ups** and **555 sets of four pieces** (2220 artworks): one face cut into Left Eye / Right Eye / Left Mouth / Right Mouth, shown as the Crop of each piece. A set's pieces share every other trait and its Stare tier (444 Glance, 83 Watch, 28 Heavy Stare sets); Face is Woman (278 sets) or Man (277 sets); the Accessory shows only on the pieces where it lands; set pieces have no Anomaly. Each piece also carries **Set #n**.
How the faces are made: every artwork starts from a black-and-white photographic portrait of a person who doesn't exist, generated by an image model (`art/portraits/manifest.json` lists every prompt and generation job): one portrait per set, and a pool of portraits for the single close-ups (each gives several crops). Women and men of many backgrounds, in even numbers. `art/neonfaces/photo.py` turns a portrait into the traits' crop, block grid, tones, grain, accessory and anomaly; only those pixels are stored on-chain, and they are the art. The Light trait matches what you see: side-lit portraits are mirrored for Right.
Rule: shrink a Face to 48 px. If you can't tell it's a NEONFACE, the trait is too weak (`python art/generate.py` writes the test sheet to `art/output/legibility_48px.png`).

## Live (on-chain) attributes

| Attribute | Source |
|---|---|
| Stare | Unrevealed until the reveal, then Glance / Watch / Heavy Stare |
| Seed | tickers of the base basket delivered at mint |
| Seed Status | Funded / Pending / Inactive |
| Stare Upgrade | top-up basket (Watch / Heavy Stare) or Pending |
| Set | 1..555 (a number), on set pieces |
| Set Status | Assembled (this Face holds the other three pieces and shows the whole face), Fused (assembled for good: the pieces can never leave, the whole face gets a one-cell neon frame) or Inside Another Piece; the description names the pieces |
| Fused Since | date, on the Face that holds a fused set |
| Set Bonus | the one-time bonus basket, on the Face that received it |
| Holds <TICKER> | live balance inside the Face account (a number) |
| Locked Until | date, while the holder has locked the account |
| Unblinking Days | days since the Face last changed hands |
| Eyes Open Since | date of the last transfer |
| Gaze | Steady / Fixed / Piercing after 30 / 90 / 365 days with the same holder; the neon blooms in the image |
| Art ID | art piece assigned at reveal |

Numbers on marketplaces: Set, Holds, Unblinking and Art ID are number traits (dates are date traits). OpenSea shows them as stats and leaves them out of trait filters and rarity scores: live balances would otherwise add a new filter value with every trade, and a Set value shared by only four Faces would rank every set piece above the rarest single. Rarity then comes from the art traits and the Stare tier. To find the other pieces of a set, the set hunter on the site lists them with their holders and an OpenSea link for each.
